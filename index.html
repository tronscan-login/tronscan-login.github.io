How to use it

From search to verification.

A blockchain explorer helps make public chain activity easier to inspect. A typical lookup follows a few simple steps.

Important: TRONSCAN is an explorer, not proof that a website, token or wallet request is safe. Independently verify contract addresses and be cautious of impersonation tokens and phishing links.
01

Enter a search term

Use a transaction ID, TRON address, block number, token name or contract address.

02

Open the matching record

Check that the address, transaction hash or contract matches what you intended to inspect.

03

Review the details

Inspect status, timestamp, sender, recipient, amount, token, fees and relevant contract data.

04

Cross-check the result

Use official project documentation and trusted sources when assessing tokens, contracts or applications.
